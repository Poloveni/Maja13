Comment fonctionnent les modifications

Les inscriptions se valident ici, en direct. Les événements, présences et annonces se gèrent sur Discord (synchronisation automatique). Les modifications de membres et de la page d'accueil sont un brouillon local : passe par Exporter, colle le code dans le fichier du site, puis publie (publier.bat).
